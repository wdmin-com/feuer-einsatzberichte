# Einsatzstichworte: переход из категорий WordPress

## Поведение

- Отчёты используют отдельную таксономию `feu_einsatzstichwort`. Она привязана к старым `post` и новым `einsatzbericht`.
- Один опубликованный отчёт учитывается в статистике один раз: приоритет у `_feu_einsatz_primary_stichwort_id`, затем у самого глубокого Stichwort. Отчёт без Stichwort попадает в «Ohne Einsatzstichwort».
- Категории WordPress в дереве `Einsätze` остаются зеркалом совместимости для существующих URL, публичных архивов и сторонних шаблонов. При активной новой структуре они скрыты в обычном списке `Beiträge → Kategorien` и классическом выборе категорий новых блог-постов; физически они **не удалены**. Во внешнем REST API и в редакторе блоков WordPress старые термины могут оставаться видимыми до окончательного отказа от зеркала.
- Участники сохраняют исторические `category_ids` с ID старых категорий. Эта колонка не смешивается с ID новой таксономии и отдельно переназначается при восстановлении архива.
- Новая чистая установка активирует отдельную таксономию автоматически. Существующая установка переключается только вручную через `Einstellungen → Einsatzstichworte`.

## Перенос существующего сайта

1. Проверить выбранные Stichworte и выполнить предварительную проверку на вкладке `Einsatzstichworte`.
2. Нажать `Sichern und Einsatzstichworte übertragen`. Плагин создаёт архив до записи новых связей.
3. Сверить число вызовов, диаграмму, редактирование и несколько URL обоих форматов: `/einsaetze/post/` и `/einsaetze/stichwort/post/`.
4. Кнопка отката доступна, только пока после переключения не добавлялись, не удалялись и не редактировались отчёты или выбранные Stichworte. Архив остаётся отдельно.

## Инварианты безопасности

- Перенос не удаляет термины, публикации, медиа и старые связи категорий.
- Кнопки переноса/отката требуют `manage_options` и nonce.
- Конфликт slug или категория вне дерева `Einsätze` останавливают перенос.
- URL сравниваются до и после копирования связей.
- Архивы новой версии включают термины `feu_einsatzstichwort`, связи с отчётами и основной Stichwort; старые архивы остаются читаемыми.
- Не удалять старые категории вручную до отдельного завершения миграции всех архивов, публичных списков и внешних интеграций.
