# Security Policy

## Supported Versions

Security support is provided only for versions used by authorized users under a personal agreement with the developer.

Unauthorized installations are not supported.

## Reporting a Vulnerability

Do not publish vulnerability details in public issues.

Report security concerns privately to:

Walter Faerber  
https://wdmin.com/

Include:

- affected plugin version;
- WordPress and PHP version;
- reproduction steps;
- affected URL or workflow;
- expected and actual behavior;
- logs or screenshots if available.

## Scope

Reports involving unauthorized copies, redistributed packages, nulled versions, or modified third-party distributions may be rejected.
