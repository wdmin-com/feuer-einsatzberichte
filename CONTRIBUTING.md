# Contributing

This is a proprietary plugin repository.

Public access to the repository does not grant usage rights.

## Contribution Rules

Contributions are accepted only after prior agreement with the developer.

Before opening a pull request, contact Walter Faerber and describe:

- the affected feature or bug;
- the reason for the change;
- whether the change affects licensing, update delivery, security, database schema, or public output.

By submitting a pull request, you agree that your contribution may be used, modified, distributed, and sublicensed by the developer as part of this proprietary software without creating any usage right for you or third parties.

## Code Expectations

- Keep changes scoped and compatible with the existing plugin architecture.
- Do not weaken permission checks, update integrity checks, backup validation, or data sanitization.
- Do not add external services, trackers, or network calls without explicit approval.
- Do not change license files or copyright notices without explicit approval.
